# filmDeveloper

A fully open-source film developer machine — built in the open, from other people's
write-ups, for anyone who wants to build their own.

## Why this exists

Darkroom chemistry is expensive, time-consuming, and honestly a bit intimidating to
get into. Plenty of people have already gone down this road and written down exactly
what worked. This project is about taking that knowledge and turning it into
something you can actually build and use, without needing a darkroom or a big budget.

Everything here is open. Every bit of it — though the actual license is still on its
way. Nothing substantive lands here before that's settled.

## Credits

This project is built entirely on knowledge that other people already shared — blog
posts, forum threads, build logs, and a lot of patient experimentation on their
parts. Every source gets listed in the References section below.

If you recognize your work in here and it's not credited, please say so. Genuinely —
getting the attribution right matters, and it's the least I can do.
